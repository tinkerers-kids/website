# Erste Schritte

Bevor du richtig loslegen kannst, brauchst du ein paar Dinge. Keine Sorge, ich helfe dir beim Einrichten!

## 1. Hardware ✅

Du brauchst einen Computer mit:
- **Tastatur** (physische Tastatur, keine Bildschirmtastatur!)
- **Maus** oder Trackpad
- **Internetverbindung**

:::warning Tablets funktionieren nicht!
❌ iPads, Android-Tablets oder Smartphones sind **nicht geeignet** fürs Mentoring.

Programmieren braucht:
- Schnelles Tippen mit beiden Händen
- Präzise Maussteuerung
- Viele Tastenkombinationen
- Mehrere Fenster gleichzeitig
:::

### Welcher Computer?

Deine Eltern haben eine von zwei Möglichkeiten gewählt:

**Option A: Eigener Computer für dich**
- Zum Beispiel ein Raspberry Pi 500+
- Nur fürs Tinkern
- Gehört dir!

**Option B: Computer der Eltern + Cloud**
- Du verbindest dich zu einem Cloud-Server
- Der Cloud-Server ist wie ein Computer im Internet
- Auf dem Computer der Eltern wird nichts installiert

## 2. Software ✅

Diese Programme brauchst du (ich helfe beim Installieren!):

### VS Code
- Deine Entwicklungsumgebung
- Hier schreibst du deinen Code
- Wie ein super-mächtiges Textprogramm

### Git
- Für Versionskontrolle
- Speichert alle Änderungen
- Wie "Rückgängig" auf Superkräften!

### Typst
- Zum Erstellen von schönen PDF-Dokumenten
- Mit Code statt Maus-Geklicke
- Wie ein modernes Word

:::tip Keine Sorge!
Du musst das nicht alleine installieren. Beim Onboarding machen wir das zusammen!
:::

## 3. GitHub Account ✅

Du brauchst einen **kostenlosen GitHub-Account**:

1. Gehe zu [github.com](https://github.com)
2. Klicke auf "Sign up"
3. Folge den Anweisungen
4. **Wichtig:** Speichere Benutzernamen und Passwort gut ab!

GitHub ist wie ein "soziales Netzwerk" für Code. Hier speicherst du deine Projekte und kannst mit anderen zusammenarbeiten.

## 4. Onboarding-Termin 📅

Beim Onboarding treffen wir uns das erste Mal:

**Was passiert beim Onboarding:**
1. Wir lernen uns kennen (Video-Call)
2. Wir richten alles zusammen ein
3. Du erstellst dein erstes Mini-Projekt
4. Ich zeige dir, wie alles funktioniert

**Dauer:** Ca. 1-2 Stunden

**Vorbereitung:**
- Computer bereit haben
- GitHub-Account erstellt
- Eltern sollten dabei sein (für technische Dinge)

## Was kommt danach?

Nach dem Onboarding kannst du loslegen!

**Dein erstes Projekt:** Ein einfaches Dokument mit Typst erstellen
- Über dich selbst
- Über ein Hobby
- Über etwas, das dich interessiert

**Dann:** Immer mehr lernen, in deinem eigenen Tempo!

## Nächste Schritte

1. ✅ Hardware bereit machen
2. ✅ GitHub-Account erstellen
3. ✅ Onboarding-Termin mit deinen Eltern vereinbaren
4. ✅ Loslegen!
